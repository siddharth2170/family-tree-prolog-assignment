# Family Tree Program in Prolog

This repository contains the Prolog source file and report for the Family Tree Program assignment.

Repository: https://github.com/siddharth2170/family-tree-prolog-assignment

## Run

With SWI-Prolog installed:

```bash
swipl -s family_tree.pl
```

Enter a query at the `?-` prompt and type `;` to request another solution.

## Files

- `family_tree.pl` contains the family facts and relationship rules.
- `Family_Tree_Program_APA7.docx` is the combined submission document.
